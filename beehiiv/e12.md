## What the assessment reads

Read-only access to seven Databricks system tables: `lakeflow.jobs`, `lakeflow.job_run_timeline`, `lakeflow.job_task_run_timeline`, `billing.usage`, `billing.list_prices`, `compute.clusters` and `compute.node_timeline`. The queries are published in full on the assessment page, so your team can read every line before anything runs.

## The questions we always get

**Does BigHammer get access to our workspace?**
No. Your own team runs the queries, in your own SQL warehouse session, under your own identity.

**Is anything installed?**
No. It's plain SQL. No libraries, agents or service principals.

**What does it write?**
One temporary view, and one result table per query in a catalog and schema you choose. Nothing else is created or changed.

**What data leaves our environment?**
Only the CSV files you export: job names and IDs, run and task records, priced usage rows, cluster configuration (including tags), and CPU and memory samples. No table data, no source code, no secrets or tokens. Open every file before you send it.

**What compute does it use?**
One SQL warehouse session for the duration of the queries.
