## How it works

1. **Open one Databricks SQL warehouse session** with read access to seven system tables.
2. **Set two values:** your numeric workspace ID, and a catalog and schema where the results can be saved.
3. **Run seven read-only queries in order.** Copy them from the assessment page. The first sets a 90-day window, and each of the others saves one result set (`collected_jobs`, `collected_parent_runs` and so on) in the schema you chose.
4. **Export each result to CSV.**
5. **Zip the files and send them to us.** CSV extracts only. No secrets, no tokens, no credentials.

Nothing is installed and nothing is changed. The queries only read system tables, and the only things they create are the result tables in your own schema.

## What you get back

- Total Databricks cost over 90 days, at published list prices.
- Cost by billing product.
- Spend traced to jobs versus untraced.
- Failed-job cost, measured.
- Per-job and per-run cost tables.
- Average worker CPU and Photon usage share.
