# BigHammer.ai webinar nurture sequence

Review site for the 24-email, 24-week post-webinar nurture sequence (Databricks cost).
Live: https://adisuja.github.io/bighammer-webinar-nurture/

- `emails/eNN.html`: ESP-ready HTML (table layout, inline styles, absolute image URLs, GoHighLevel merge tags)
- `emails/eNN.txt`: plain-text alternative
- `img/eNN.jpg`: hero visual for each email
- `data.json`: subjects, preheaders, schedule and every UTM-tagged link

Source and build script live in the private working folder (`webinar-nurture/build.py`).
